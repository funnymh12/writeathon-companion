# 开发日志 (Productivity & Robustness)

## 2026-02-05: 剪藏体验深度优化

### 1. 智能 Markdown 增强 (Smart Markdown)
针对微信公众号等平台的各种不规范格式进行了自动修复：
- **列表修复**: 自动识别 `1、` `1.`(无空格) `•` 等伪列表，转换为标准 Markdown 列表。
- **格式净化**: 移除加粗文本内部的多余空格 (`** text **` -> `**text**`)，将标点移出加粗范围 (`**text。**` -> `**text**。`)。
- **元数据**: 自动在剪藏头部添加 `Clipping Date` 和 `Source URL`。

### 2. AI 对话剪藏升级 (AI Chat Clipper)
- **Gemini 适配**: 深度适配 Gemini 最新 DOM 结构，修复了多轮对话乱序的问题，自动过滤无关 UI 元素。
- **豆包优化**: 继续保持“思考过程”分离特性，清洗界面干扰文本。
- **角色标注**: 统一使用 H4 + Emoji (`#### 🙋 User` / `#### 🤖 AI`) 区分对话角色，提升可读性。

### 3. 本地化存储 (Local Save)
响应用户对数据掌控的需求，新增了“本地保存”功能：
- **Markdown 下载**: 文章/对话模式下，可直接下载为 `.md` 文件，包含完整的 YAML Frontmatter (标题、链接、时间)。
- **批量图片下载**: 图片提取模式下，支持批量选择图片并打包为 `.zip` 下载。
- **智能重命名**: 
    - Zip 包命名: `标题(前10字)_日期时间.zip`。
    - 图片命名: 优先使用 `Alt` 文本，或者自动使用 `标题_序号`，确保文件名有意义。
- **格式统一**: 所有下载的图片（包括 WebP）都会自动转换为兼容性更好的 `JPG` 格式。
