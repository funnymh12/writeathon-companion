# 开发日志 (Engineering & Design Upgrade)

## 2026-02-05: Design System Upgrade "Teal Glass" & Engineering Robustness

### 1. 视觉与体验进阶 (UI/UX 2.0)
对 Writeathon Companion 插件 UI 进行全面升级，旨在摆脱 MVP 阶段的"默认样式感"，打造符合 Writeathon 品牌调性（青色/Teal）的高级感界面。

- **深色模式 (Dark Mode)**:
    - 基于 Tailwind CSS `darkMode: 'class'` 实现了全站暗色适配。
    - 重构了 CSS 变量系统 (`--background`, `--foreground`, `--primary` 等)，支持主题自动切换。
- **设计系统 (Design System)**: 
    - **配色**: 引入 `Slate` 灰度色阶与品牌色 `Teal` (#4DB6AC) 变体。
    - **质感**: 全局引入 Glassmorphism (毛玻璃) 风格 (`.glass`)。
    - **动效**: 添加全局 `slideUpFade` 进场动画与 `hover-lift` 交互。
    - **字体**: 移除了 Google Fonts，改用 `System Font Stack` 提升加载速度。
- **组件重构**:
    - **App Shell**: 悬浮半透明 Header，底部导航增加辉光点缀，背景调整为极淡青色径向渐变。
    - **Memo**: 沉浸式无边框输入，引用块采用渐变背景，底部工具栏悬浮化。
    - **Clipper**: 统一视觉语言，优化“全文/图片”切换开关，图片网格增加高亮动画。
    - **Settings**: 表单控件全面圆角化，开关组件增加描述与图标。

### 2. 工程化基础设施 (Infrastructure)
- **自动化打包 (`scripts/package.cjs`)**: 
    - 新增自动化构建脚本，一键执行 Build -> Version Sync -> Zip Packaging。
    - 解决了手动压缩易出错的问题，产物符合 Chrome Web Store 规范。
- **单元测试体系 (Testing)**:
    - 引入 **Vitest** + **JSDOM** 测试框架。
    - 为核心解析逻辑 `src/utils/content-parser.ts` 编写了全面测试用例（覆盖 HTML 解析、公众号、DeepSeek 思考链提取）。
    - 修复了 Turndown 规则导致的 Markdown 格式丢失 Bug。

### 3. 代码质量与健壮性 (Robustness)
- **API 错误处理重构**:
    - 在 `src/utils/api.ts` 中标准化了 `ApiError`, `AuthError`, `NetworkError` 类。
    - 增加了全局拦截器：
        - **401 Unauthorized**: 明确提示 Token 过期。
        - **429 Too Many Requests**: 提示限流。
        - **500+**: 提示服务端异常。

### 4. 实验性功能 (Experimental)
- **DeepSeek 支持**: 新增 `chat.deepseek.com` 解析策略，智能提取并区分 `<think>` 思考过程。
- **离线草稿**: Memo 内容自动保存到 `localStorage`，意外关闭可恢复。
