# 🚀 写拉松小助手 (Writeathon Companion) 使用指南

欢迎使用 **写拉松小助手**！这是一个专为创作者、研究者和知识管理爱好者打造的浏览器增强插件。它不仅能帮你把互联网上的碎片信息瞬间变为私人知识库，还能通过 AI 激发你的无限灵感。

---

## 🌟 插件亮点

1.  **禅意设计 (Zen Design)**：基于“禅意纸张”与“磨砂玻璃”美学，提供极致专注的视觉体验。
2.  **智能剪藏 (Smart Clipper)**：深度适配微信公众号、知乎及主流 AI 对话平台（如 ChatGPT、DeepSeek），完美解析图片与排版。
3.  **AI 对话提取**：自动区分 AI 思考过程与正式回答，角色标注一目了然。
4.  **无缝同步**：一键将内容同步至 Writeathon 云端，支持多空间管理。
5.  **离线保护**：内置草稿自动保存，防止因意外关闭导致灵感丢失。

---

## ⚙️ 快速配置（新手必读）

只需三步，即可开启高效之旅：

1.  **获取 Token**：登录 [Writeathon 官网](https://writeathon.cn)，在“个人设置”-“API设置”中复制你的 `Access Token`。
2.  **绑定插件**：点击插件右上角的 **齿轮图标** 进入设置页面，将 Token 粘贴到 `Writeathon Token` 框中并点保存。
3.  **配置 AI（可选）**：如果你需要使用助手功能，可以在设置中填入你的 Gemini 或 OpenAI API Key。

---

## 🛠️ 五大核心板块

-   **📝 速记 (Memo)**：
    *   **作用**：随时记录突发奇想。
    *   **亮点**：支持 Markdown 简写，右下角可切换保存的空间。
-   **🕒 最近 (Recent)**：
    *   **作用**：查看并搜索云端历史卡片。
    *   **亮点**：支持**全文搜索**（不只是搜标题，还能搜正文！），内容会后台自动加载预览。
-   **✂️ 剪藏 (Clipper)**：
    *   **作用**：把网页文章或图片“搬”回家。
    *   **亮点**：
        *   **全文模式**：一键将整篇文章转为完美的 Markdown。
        *   **图片提取**：自动识别网页高清大图，支持批量选择保存。
-   **✨ 灵感 (Prompt)**：
    *   **作用**：写作模板与提示词库。
    *   **亮点**：内置常用专业写作 Prompt，点击即可直接使用或编辑。
-   **🤖 助手 (AIChat)**：
    *   **作用**：你的私人创作陪练。
    *   **亮点**：深度交互，支持自定义模型，帮助你润色文本或头脑风暴。

## 💡 使用场景与小技巧

### 场景 1：微信文章深度阅读
*   看到一篇深度长文想保存？打开**剪藏**，插件会自动剔除广告和杂质，只保留干货。
*   **小技巧**：即使图片有防盗链，插件也会利用内置服务帮你自动转储，确保永久可见。

### 场景 2：研究 AI 对话
*   在与 DeepSeek 或豆包对话后，想保存这段精彩回复？点开**剪藏**，它会自动识别出哪些是 AI 的“思考过程”，哪些是正式结论，并结构化保存。

### 场景 3：碎片灵感捕捉
*   工作时突然想到一个金句？按下 **Alt+S**（默认快捷键）直接唤起弹窗，在**速记**中打完收工。
*   **小技巧**：不用怕网络断开，插件会先存在本地，网络恢复后再发送。

### 场景 4：极简定制
*   觉得图标太多？在设置中可以**自定义开关模块**。如果你只需要剪藏，可以把其他 4 个按钮全部隐藏，享受清爽界面。
